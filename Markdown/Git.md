### thư mục/file mới
-`git init`  ->	Khởi tạo Git cho thư mục hiện tại
-`git status` ->	Kiểm tra trạng thái các file
-`git add .`  ->	Đưa tất cả file vào staging area
-`git status` ->	Kiểm tra lại những file chuẩn bị commit
-`git branch -M main` ->  Đổi tên branch hiện tại thành main
-`git commit -m "new"`	-> Lưu một phiên bản vào Git
-`git remote add origin (link github)`  ->  Kết nối Git local với repository trên GitHub
-`git push -u origin main` ->  Đẩy branch main lên GitHub
