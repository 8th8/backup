 ## Function < Hànm > có 3 loại:
- `Function declarations` : Khai báo hàm
- `Function expressions`  : Biểu thức hàm
- `Arrow Function`        : Hàm mũi tên 

## Parameter : Tham số
## Argument = đối số  < giá trị mà bạn truyền vào một function >
### Error 
- `ReferenceError` -> lỗi tham chiếu
- `TypeError` -> lỗi kiểu dữ liệu

## phép tính
- `add ` : cộng  (+)
- `subtract` : trừ (-)
- `multiply` : nhân (*)
- `divide` : chia (/)

## từ vựng
- `access` : truy cập
- `initialization` : khởi tạo
- `initialized` : đã khởi tạo
- `Reinitialized ` :  khởi tạo lại
- `existing` : đã tồn tại
- `empty` : trống, chưa có gì
- `repository` : thư mục dự án
- `Artificial` : nhân tạo
- `Intelligence` : trí tuệ
- `branch` : nhánh
- `On branch master` : → Đang ở trên nhánh master.
- `commit` : commit, lưu một phiên bản thay đổi vào Git
- `yet` : vẫn chưa, cho đến bây giờ
- `changes` : những thay đổi
- `to be` : sẽ được
- `Changes to be committed` : → Các thay đổi sẽ được commit.
- `working tree` :  thư mục/project bạn đang làm việc
- `clean` :  sạch, không có thay đổi chưa được xử lý
- `working tree clean` :  → Project hiện tại không có thay đổi chưa commit.
- `src` :  source = nguồn
- `refspec` :  specification của reference = chỉ định branch/tag cần push
- `does not match` :  không khớp / không tìm thấy
- `any` :  bất kỳ
- `error: src refspec main does not match any` :  Không tìm thấy branch main để push.
- `enumerating` :  đang liệt kê, đếm
- `counting` :  đang đếm
- `delta` :  phần chênh lệch, phần thay đổi
- `compression` :  sự nén
- `compressing` :  đang nén
- `up to` :  tối đa
- `threads` :  các luồng xử lý
- `reused` :  được sử dụng lại
- `pack` :  gói dữ liệu
- `delta` :  phần thay đổi/chênh lệch
- `set up` :  thiết lập
- `track` :  theo dõi
