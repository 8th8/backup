# 📚 GHI CHÚ LẬP TRÌNH JavaScript


```js
Rename biến (Đừng sửa từng chỗ bằng tay.) hãy click vào biến -> F2 tên biến đó -> sẽ đổi toàn bộ tên biến thành tên mới
```
### ghi chu:

- `map() `: dùng để tuyệt từng phần tử trong mảng
- `fitter() `: dùng để lọc phần tử theo điều kiện 
- `reduce() `: gom lại thành một giá trị ( tổng, tích, object.....)  
-

### ghi chu 2:
- `preventDefault()` trong JavaScript dùng để ngăn hành vi mặc định của trình duyệt khi một sự kiện xảy ra.
- `trim()` trong JavaScript dùng để xóa khoảng trắng ở đầu và cuối chuỗi (string).
